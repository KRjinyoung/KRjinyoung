### 🚀 What I'm working on

- 🎟️ **DOON** — a fair, real-time ticketing platform. Edge time-sync over KOREN nationwide PoPs evens out regional network latency, plus AI-based macro detection. *(Team Doon)*
- 🎥 **Task-aware MOSA** — task-aware semantic scoring for adaptive video streaming, using CLIP to predict task sensitivity.
- 📈 **Quant Lab** — a personal research lab for systematic strategies on US equities.
